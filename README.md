# Team4 Aria

A responsive React and TypeScript real-estate presentation site for Team4 Aria. Public enquiries are written through a Vercel server function, and the private admin panel reads the same Firestore `enquiries` collection through UID-authorized server endpoints.

## Local development

```bash
npm install
npm run dev
```

`npm run dev` serves the Vite frontend only. To exercise `/api` functions locally, keep the project’s single ignored `.env` file populated from `.env.example`, then run:

```bash
npm run dev:vercel
```

Do not create `.env.local` or additional environment files. `.env` is ignored by Git; `.env.example` must contain placeholders only.

## Firebase setup

1. In Firebase Console, select project `team4aria-77f44`.
2. Under **Build → Firestore Database**, create Cloud Firestore in Native mode if it is not already enabled.
3. Under **Build → Authentication → Sign-in method**, enable **Email/Password**.
4. Under **Authentication → Users**, create the first real administrator with an owner-approved email and a strong temporary password. Do not add an invented or shared account.
5. Open that user and copy the Firebase Authentication **UID**.
6. Add that UID to the server-only `ADMIN_ALLOWED_UIDS` environment variable. Multiple approved UIDs are comma-separated.
7. Review the deployed Firestore rules. This repository denies every browser read/write operation on `enquiries` and `enquiryIdempotency`; Firebase Admin performs authorized server operations outside client rules.
8. If this Firebase project has unrelated collections, merge the two lead-collection deny blocks into the existing rules without replacing or weakening the other rules. Deploy only after review with `firebase deploy --only firestore:rules`.

The Firebase web configuration in `src/admin/firebaseClient.ts` is public browser configuration used only for Authentication. It does not grant Firestore access or contain service-account credentials.

### Required Vercel environment variables

- `FIREBASE_PROJECT_ID` — `team4aria-77f44`
- `FIREBASE_CLIENT_EMAIL` — service account JSON `client_email`
- `FIREBASE_PRIVATE_KEY` — complete service account JSON `private_key`, preserving newline escapes
- `ADMIN_ALLOWED_UIDS` — comma-separated Firebase Authentication UIDs approved for the private panel

Set these only in Vercel’s server environment. Never use `VITE_` prefixes for service-account values or the UID allowlist. Environment changes require a new deployment.

## Public enquiry flow

- `POST /api/enquiries` validates and normalizes the existing form fields, enforces a 16 KB request limit, checks a hidden honeypot, and rejects malformed input.
- Lead documents use autogenerated IDs in `enquiries`, with a server timestamp, `new` status, the canonical project name, consent, and limited source metadata.
- Hashed idempotency markers in `enquiryIdempotency` prevent duplicate records for a retried submission.
- The Thank You route is shown only after the API confirms a successful save.

## Private admin panel

- `/admin` signs in with Firebase Email/Password Authentication.
- `/admin/leads` is shown only after the server verifies the Firebase ID token and finds its UID in `ADMIN_ALLOWED_UIDS`.
- Session verification, listing/counting, CSV export, and deletion each repeat the server-side token and UID check.
- Search, date filters, sort, result totals, and pagination operate on real saved Firestore records.
- CSV export supports all matching records or explicitly selected records, includes a UTF-8 BOM for Excel, escapes quotes/newlines/commas, and neutralizes spreadsheet-formula prefixes.
- Lead deletion requires a named confirmation and removes the related idempotency marker as well as the lead.
- PDF export is intentionally not exposed; CSV is the supported export format for this phase.

```bash
npm run typecheck

```

## Content sources

- Public brand/contact configuration: `src/config/site.ts`
- Approved project facts and FAQ copy: `src/data/projects.ts`
- Public enquiry form/client: `src/components/EnquiryModal.tsx` and `src/services/enquiryService.ts`
- Private admin UI: `src/admin/`
- Server authorization, Firestore queries, export, and API entrypoints: `server/` and `api/admin/`

The supplied assets under `src/assets/` still require final client confirmation for usage rights and publication approval.
